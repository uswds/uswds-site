- **Multiselectable accordion groups.** Add the `data-allow-multiple` attribute to any `usa-accordion` to create a multiselectable accordion group.
- **Default an accordion button to open.** Add the `aria-expanded="true"` attribute to any `usa-accordion__button` to have that section open by default at page load. When the accordion is initialized, the JavaScript will automatically add `aria-expanded="false"` attribute to all other accordion buttons.
- **Accordion icon position.** The expand/collapse icon defaults to the start side of the accordion. “Start” refers to the reading order of the language — this means for languages that are read left to right (English, Spanish, etc.), the expand/collapse icon will default to the left. For languages that are read right to left (Arabic, Hebrew, etc.), the expand/collapse icon will default to the right. Previous to USWDS 3.14.0, the icon defaulted to the end side.
- **Set icon position.** To change accordion icon placement everywhere an accordion appears, use the `$theme-accordion-icon-position` setting (`"start"` or `"end"`). To change icon placement for a single accordion, add `usa-accordion--icon-start` or `usa-accordion--icon-end` to the accordion root.
